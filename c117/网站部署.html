部署说明（GitHub Pages / Quarto）

本目录是一个纯静态单页工具：index.html + style.css + calculator.js + app.js， 无构建步骤、无后端、无外部依赖。目标地址：

https://bonewok.github.io/c117/

1. 目录内容

文件 作用
index.html 页面结构（表单 + 结果容器）
style.css 样式（跟随系统浅色/深色，含手机与打印适配）
calculator.js 计算内核，与 cloning_calculator_v2.py 逐行对应
app.js 表单交互、结果渲染、复制与 URL 分享
tests/fixtures.json 542 组基准用例（由 Python 版生成）
tests/parity.test.js Node 脚本：逐字段比对 JS 与 Python 结果

2. 本地预览

直接双击 index.html 即可（file:// 也能正常计算）。

或起一个本地静态服务：

cd c117
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/

3. 部署到你的站点

你的站点是 Quarto website（main 分支源码，Actions 发布到 gh-pages）。

  1. 把整个 c117/ 目录放到仓库根目录（与 index.qmd、_quarto.yml 同级）。

  2. 在 _quarto.yml 的 project: 下声明资源，确保 Quarto 原样拷贝：

    project:
  type: website
  resources:
    - c117/**

  3. 提交并推送：

    git add c117 _quarto.yml
git commit -m "add C117 cloning calculator page"
git push origin main

  4. 等 Actions 的 Quarto Publish 跑完，访问 https://bonewok.github.io/c117/。

没有 resources 时，Quarto 只拷贝被引用的资源，c117/ 可能不会出现在 _site 里， 表现为 404。加上即可。

4. 在首页加入口

在 index.qmd 的「工具」表格里加一行，例如：

| **🧬 分子克隆** | **[C117 加样计算器](c117/)** | ClonExpress Ultra One Step Cloning Kit V3 单片段同源重组 10 μL 体系：质量归一化、体积分配、工作液稀释方案。 | 纯前端、可分享链接、可复制加样表 |

6. 修改算法时如何保持一致

网页版与命令行版必须同步，流程如下：

  1. 先改 cloning_calculator_v2.py（唯一权威实现）；

  2. 在项目根目录重新导出基准用例：

    python export_web_fixtures.py

  3. 同步修改 c117/calculator.js；

  4. 跑一致性测试（Node 18+）：

    node c117/tests/parity.test.js

    输出 OK: ... 0 mismatches 才算通过。测试会逐字段比对数值、分配说明、 警告文案和校验结果，能捕获公式、分支、取整（C printf 半偶舍入）的任何偏差。

7. 常见问题

  • 打开是 404：确认目录名是 c117、已加 resources、Actions 构建成功。
  • 样式没生效：检查 style.css 是否与 index.html 同目录，强刷（Ctrl+F5）。
  • 改了页面但线上没变：Pages 有缓存，等 1–2 分钟或换无痕窗口。
  • 分享链接参数：?vl=&vc=&il=&ic=&mp=&df= 分别对应 Vector 长度/浓度、Insert 长度/浓度、最小加样体积、工作液终体积。
  • 浏览器兼容：需要 BigInt（Chrome/Edge 67+、Safari 14+、Firefox 68+）， 用于与 Python 完全一致的定点舍入；老旧浏览器可能显示异常。
